# 🚀 CampusHub

A decentralized campus event registration platform built on the Monad Testnet.

CampusHub allows students to discover campus events, connect their MetaMask wallet, and register for events with their participation recorded on-chain.

## 🌐 Network

- Network: Monad Testnet
- Chain ID: 10143
- Token: MON
- RPC: https://testnet-rpc.monad.xyz

Install frontend dependencies:

cd frontend
npm install

Start the development server:

npm run dev
